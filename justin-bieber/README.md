# JUSTIN BIEBER – fan stránka

Česká fan stránka věnovaná Justinu Bieberovi.

## Obsah
- Životopis a začátky kariéry
- Časová osa
- Přehled vybraných alb
- Fotogalerie (obrázky načítané z Wikimedia Commons)
- Odkazy na hudební videa na YouTube

## Spuštění
Otevři soubor `index.html` v prohlížeči.

Fotografie jsou načítány z Wikimedia Commons; u každého původního souboru je třeba respektovat uvedenou licenci a autora. Stránka není oficiálním webem interpreta.
