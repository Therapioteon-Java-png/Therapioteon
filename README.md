# THERAPIOTEON-JAVA – web

Tato složka obsahuje statický web. Web je oddělený od samotné Windows aplikace.

## Zveřejnění přes GitHub Pages
1. Otevři Settings → Pages.
2. V části Build and deployment vyber Deploy from a branch.
3. Zvol větev main a složku /(root), potom Save.
4. Veřejná adresa bude obvykle https://Therapioteon-Java-png.github.io/Therapioteon/.

## Instalační EXE
Tlačítko stahování odkazuje na:
https://github.com/Therapioteon-Java-png/Therapioteon/releases/latest/download/THERAPIOTEON-JAVA.exe

Aby odkaz fungoval, vytvoř v repozitáři Releases → Create a new release a přilož skutečný soubor s přesným názvem THERAPIOTEON-JAVA.exe. Web sám žádný instalační program nevytváří.
